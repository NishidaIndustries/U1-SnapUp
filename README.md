# [Project Log] Project SnapUp: Custom Multi-Panel U1 Extension Kit

## Overview
Project SnapUp is a concept for an open-source hardware expansion kit designed specifically for the Snapmaker U1 platform. The objective is to optimize filament pathing, active multi-stage air filtration, and secondary material storage within a compact footprint.

This project is fully open-source. Upon mechanical validation, all CAD files, 3MF/STL print profiles, and a complete Bill of Materials (BOM) will be uploaded to GitHub under the GNU GPL-3.0 license.

## Core Features & Mechanical Specifications

1. Multi-Height Clearance Cable & Guide Layout
* Engineered with a staggered vertical pathing system for cables and lines.
* Designed to prevent crossing PTFE filament tubes from colliding or binding during toolhead changes, maintaining a low-profile clearance.

2. Snap-On Airtight Filament Enclosure
* A sealed filament storage dry box designed to mount directly onto the Snapmaker U1's stock filament holders without tool modifications.
* Uses an active desiccant layout to preserve engineering-grade materials from ambient moisture.

3. High-Observation Top Enclosure
* Features a transparent acrylic top panel secured by high-strength magnets for quick monitoring.
* Integrates low-profile internal RGB/White illumination and a side-mounted Honeycomb Storage Wall (HSW) grid for quick-access tool organization.

4. Dual-Panel Air Extraction & Air Scrubbing
* Incorporates active extractor fans into both the custom rear panel and the top enclosure.
* Routes internal air through a dual-stage filtration cartridge using HEPA elements for micro-particles and activated carbon to neutralize VOCs.

## Current Project Status
* Phase 1: Completing 2D hand-sketches, structural clearance calculations, and block wiring diagrams.
* Phase 2: Planning rapid prototyping using standard PLA configurations for physical fitment checks before moving to final structural components.
