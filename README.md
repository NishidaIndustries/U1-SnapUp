# Project SnapUp: Ultimate Snapmaker U1 Upgrade Choice

## Project Overview
Project SnapUp is a comprehensive, completely open-source hardware expansion kit engineered specifically to upgrade the Snapmaker U1 platform. It optimizes space efficiency, filament management, heavy-duty air filtration, and structural utility into a compact footprint without sacrificing performance. 

This project is fully open-source and will include complete CAD files, 3MF/STL print profiles, a full Bill of Materials (BOM), and direct part sourcing links upon official release.

## Core Structural & Functional Features

### 1. Multi-Height Collision-Prevention Cable & Guide System
* **Compact Pathing:** Incorporates a custom-engineered, multi-height staggered cable and guide layout.
* **PTFE Protection:** Explicitly prevents crossing PTFE tubes from colliding or binding during high-speed print transitions, allowing the toolhead to glide flawlessly within a tighter, low-profile footprint.

### 2. Snap-On Airtight Filament Enclosure
* **Toolless Integration:** Features an airtight filament storage dry box designed to snap directly onto the Snapmaker U1's existing stock filament holders.
* **Moisture Protection:** Replaces traditional silica gel setups with an active desiccant layout, ensuring sensitive engineering-grade materials remain bone-dry and print-ready.

### 3. High-Observation Top Enclosure & Integrated Modules
* **Magnetic Viewing Panel:** The custom top cover features a crystal-clear, transparent acrylic viewing piece secured by high-strength magnets for easy detachment and clear visibility.
* **Integrated Lighting & Storage:** Features customizable, low-profile RGB/White illumination alongside a seamlessly integrated side-mounted **Honeycomb Storage Wall (HSW)** for rapid-access tool and nozzle organization.

### 4. Advanced Dual-Panel Air Extraction & Multi-Stage Filtration
* **Twin Extractor Array:** Engineered with dedicated high-airflow extractor fans integrated directly into both the top panel assembly and the custom back panel matrix.
* **Medical-Grade Filtration:** Both air exit pathways feature heavy-duty, dual-stage filter cartridges packed with premium **HEPA filters** to capture fine ultra-particulates and **activated carbon** to thoroughly neutralize chemical VOCs and fumes.
